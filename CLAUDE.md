# CLAUDE.md

Runa is an opinionated, Rails-inspired Python framework for agentic AI.

conventions: @RUNA.md

## Rules
- `make check` (format, lint, typecheck, test) must pass before work is done.
- Commits: one line, `<type>: <summary>`. Type is feat, fix, docs, refactor, or test.

## Principles
- Optimize for programmer happiness: Prefer APIs and designs that make the common path obvious, pleasant, and productive.
- Convention over configuration: Establish strong defaults and conventions. Make the right thing the easy thing.
- The menu is omakase: Runa should make thoughtful choices for developers instead of exposing configuration for every possible preference.
- No one paradigm: Use the simplest appropriate abstraction for the problem.
- Exalt beautiful code: Prefer code that is clear, cohesive, expressive, and pleasant to read. Treat simplicity and elegance as engineering goals.
- Provide sharp knives: Keep the framework simple and safe by default, but do not unnecessarily prevent experienced developers from doing powerful things.
- Value integrated systems: Prefer cohesive, integrated solutions over assembling many independent abstractions and tools.
- Progress over stability: Prefer meaningful improvement and evolution over preserving imperfect designs merely because they already exist. Keep compatibility when it is valuable, not as an absolute.
- Push up a big tent: Keep Runa broadly useful. Support different approaches when they fit naturally rather than making the framework ideological or unnecessarily restrictive.
